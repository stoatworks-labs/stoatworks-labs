<h1 align="center">Stoatworks Labs</h1>
<p align="center"><em>Open tools for the people who run the show.</em></p>

Stoatworks Labs is one AV tech who does sound, vision and RF for a living and writes
the software I keep wishing someone else had written. Lately I've started designing
the hardware to go with it as well, which nobody saw coming, least of all me. It
covers audio, video, RF, content and show control, and it's all free and open source.

**It works without the internet.** Everything runs on your machine and your network.
You don't need an account, and nothing phones home. Venue WiFi is lovely when it
works, and I've never once wanted a show to depend on it.

**It says what's been tested.** Every repo says what has run on real kit and what has
only ever run on my desk. If I haven't tried something on a show, I'll tell you.

**It's built with AI, and says so.** Most of this code is written with
[Claude](https://claude.com/claude-code) (Anthropic), directed and reviewed by a human who
runs shows, which is me. Every repo says so at the top, next to what has and hasn't been
tested.
